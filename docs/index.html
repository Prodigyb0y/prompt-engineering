O que é um prompt?

Em uma frase: prompt é a instrução que você escreve para a IA.

Pense na IA como um profissional muito rápido que não conhece o seu contexto. O que ele entrega depende de como você pede: o que fazer, em que formato, com quais regras e se há exemplos de um bom resultado. Esse texto de pedido é o prompt.

A tarefa deste laboratório serve para qualquer área: alguém escreve um pedido de compra em texto livre (como num e-mail) e o sistema precisa transformar isso em dados organizados. Um advogado faria o mesmo com cláusulas de contratos, e um time de RH, com currículos.

Por que engenharia de prompt?

É escolher e testar a forma de pedir, em vez de confiar na primeira tentativa.

Resposta no formato certo

Sem instrução, a IA responde em texto solto. Com o formato definido, devolve dados que um sistema lê sem retrabalho humano.

Menos erro nos casos difíceis

Regras claras dizem o que fazer quando falta dado, o valor vem em outro formato ou o texto é confuso.

Custo e velocidade sob controle

Cada técnica gasta uma quantidade diferente de texto (tokens) e demora um tempo diferente. Dá para escolher a que compensa.

Resultado que se pode auditar

Com prompt versionado e gabarito fixo, qualquer pessoa confere se a mudança melhorou de verdade.

Esses são os motivos para medir, não uma promessa: este teste usa um modelo e 50 casos e não prova o mesmo para outras tarefas.

As quatro técnicas comparadas

Todas recebem os mesmos 50 textos e devolvem o mesmo JSON. Só muda a forma de pedir.

Diferenças em uma tabela

Tokens são pedaços de texto cobrados pela API; a média é por resposta, nos casos rodados.

Leitura honesta do resultado

De onde vêm os erros

Cada resposta errada foi classificada pela causa. Contagem de respostas, não de casos.

Acerto por caso

Maior é melhor. A barra preta mostra o intervalo de confiança de 95%: se duas faixas se sobrepõem, não dá para dizer que uma técnica é melhor que a outra.

Custo por caso (US$)

Menor é melhor. Tokens informados pela API × preço de tabela.

Latência média por chamada (s)

Menor é melhor. Tempo medido com time.perf_counter.

Onde cada técnica acerta ou erra

Acerto por tipo de caso, com a contagem de respostas certas. Cada tipo tem poucos casos: leia como pista, não como prova. Toque numa célula para abrir o tipo no explorador.

Verde: 100%. Amarelo-claro: 90% ou mais. Amarelo: 70% ou mais. Vermelho: abaixo de 70%. O número sempre aparece, a cor só ajuda.
