1. O que é um prompt?

Em uma frase: prompt é a instrução que você escreve para a IA.

Pense na IA como um profissional muito rápido que não conhece o seu contexto. O que ele entrega depende de como você pede: o que ele deve fazer, em que formato, com quais regras e se há exemplos de um bom resultado. Esse texto de pedido é o prompt.

A tarefa deste laboratório é típica de qualquer área: alguém escreve um pedido de compra em texto livre (como num e-mail) e o sistema precisa transformar isso em dados organizados (item, quantidade, valor, prazo, fornecedor). Um advogado faria o mesmo com cláusulas de contratos, e um time de RH, com currículos.

Entrada (texto livre):  "Oi, preciso de 25cx de etiqueta adesiva para Compras. R$ 2450,75 cada, com a Distribuidora Pinheiro, até 17-ago-2026."

Saída esperada (dados organizados):  item, quantidade 25, unidade cx, valor 2450.75, moeda BRL, fornecedor, prazo 2026-08-17

2. Por que engenharia de prompt?

Engenharia de prompt é escolher e testar a forma de pedir, em vez de confiar na primeira tentativa.

Resposta no formato certo

Sem instrução, a IA responde em texto solto. Com o formato definido, ela devolve dados que um sistema consegue ler sem retrabalho humano.

Menos erro nos casos difíceis

Regras claras dizem o que fazer quando falta dado, quando o valor vem em outro formato ou quando o texto é confuso.

Custo e velocidade sob controle

Cada técnica gasta uma quantidade diferente de texto (tokens) e demora um tempo diferente. Dá para escolher a que compensa.

Resultado que se pode auditar

Com o prompt versionado e um gabarito fixo, qualquer pessoa confere se a mudança melhorou de verdade ou só pareceu melhorar.

O que este teste mostrou:

Os quatro pontos acima são os motivos para medir. Este teste usa um modelo e 50 casos, então não prova que as técnicas se comportam assim em outras tarefas.

3. As quatro técnicas comparadas

Todas recebem os mesmos 50 textos e devolvem o mesmo JSON. Só muda a forma de pedir.

4. Resultado por técnica

Cada linha é uma técnica, medida nos mesmos casos (resultado oficial).

Como ler: acerto por caso conta um caso como certo só se os 8 campos estiverem certos. IC 95% é a faixa em que o acerto verdadeiro provavelmente está; se as faixas de duas técnicas se sobrepõem, não dá para dizer que uma é melhor. Custo por acerto é o gasto total dividido pelos casos certos.
